# Report viewer branding

The local report viewer is named **SIlens**. Its browser title is `SIlens Results`. The header, sidebar, collapsed sidebar and favicon use a simple S mark. The brand is not an external link. Accessible names identify the viewer and describe controls.

Remove upstream cloud promotions from the viewer. Describe local rendering and optional external email delivery separately. Do not promise a SIlens cloud service or make third-party privacy guarantees.

Preserve historical report text, finding identifiers, the `strix view` command, existing browser storage keys, licenses and upstream attribution. Do not change the scanner or backend. Verify the bundled static viewer with the same synthetic report before and after the change at desktop and mobile widths, with the sidebar collapsed and a finding open. No scan is needed.
